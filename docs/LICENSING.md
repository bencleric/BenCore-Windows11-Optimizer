# Licensing BenCore

This starter repository **does not include a LICENSE file**. Do not assume others may redistribute or modify the software merely because they can view the source.

Before accepting outside contributions or allowing broad reuse, the repository owner (Benie Mansueto Vison) should choose a license after verifying ownership of all code and third-party assets.

- **MIT** is a permissive option for people who want others to use, modify and distribute their code with attribution and warranty disclaimer.
- **Apache-2.0** is another permissive option with explicit patent terms.
- **GPL-3.0** is a copyleft option that requires certain distributed derivatives to make corresponding source available under the same license.
- **No open-source license** can be appropriate if the owner is not yet ready to grant reuse permissions. It can discourage outside contributions and reuse.

These descriptions are general information, not legal advice. GitHub's repository settings can add a license when the owner has decided.
