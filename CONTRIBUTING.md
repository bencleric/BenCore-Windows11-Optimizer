# Contributing to BenCore

Thank you for your interest in improving BenCore.

**Before proposing code changes:** BenCore currently ships without an open-source license. Please contact the repository owner or open a discussion to agree on contribution permissions and licensing first. Do not submit third-party copyrighted code without permission.

Useful contributions include read-only diagnostics, documentation improvements, accessibility fixes, tests for Windows PowerShell 5.1, and safer rollback behavior.

When proposing a change, describe the Windows edition/build tested, whether the action changes the registry, how to preview it, and how it can be reversed. Never recommend disabling security protections merely to reduce process count.
