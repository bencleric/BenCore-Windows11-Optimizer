# BenCore v1.0 (initial rebuilt release)

- New dark-mode Windows desktop dashboard (PowerShell WPF), distinct from the original batch CLI.
- First-party product branding: BenCore; "Optimize the Core. Unleash the Performance."; developed by Benie Mansueto Vison.
- RAM-adaptive Lite / Balanced / Workstation profile suggestions.
- Six live PC/drive/memory metrics and top memory-using processes.
- Eight individually selectable, documented per-user registry optimization categories.
- Explicit registry preview and consent; no unattended optimization.
- Persistent backup *before* writes, rollback on failed application, per-session restore with conflict handling.
- Current-user startup manager (disable and restore HKCU Run entries).
- Local logs and recovery history.
- No forced pagefile resizing, Service Host threshold changes, blanket service changes, security disabling, or risky network tweaks.
